Ratio limits: any IMC → maximum 3 patients; MS-only → maximum 4. Reserved empty beds also use capacity, but never count as patients for workload balance.
Preferences: avoid single-patient assignments first; favor 3 IMC, then 2 IMC + open, then 2 IMC + 1 MS, then 1 IMC + 2 MS. Favor 4 MS or 3 MS + open over unnecessary mixing. Small walking increases are acceptable for same-class groups; long spans can justify mixing. The search can skip rooms.
Manual workflow: select an RN, choose available rooms, then Lock RN. Optimization replaces unlocked assignments and preserves each locked RN exactly. Release assignment frees one RN’s rooms. Clear unlocked assignments keeps all locks.
Only the selected number of additional open beds is reserved when capacity and the hard maximum span allow; other empty rooms stay unassigned. Validate reports unassigned patients and separately lists unreserved empty beds. The empty-room setting is a preference, not a safety limit.
